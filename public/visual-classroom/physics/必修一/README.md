# 物理必修一 · 3D 交互课件

本目录为 **人教版高中物理必修一** 系列 3D 交互式教学演示，基于 Three.js 纯前端实现，无需后端依赖，可直接在浏览器打开。

## 课件列表

| 文件名 | 对应知识点 | 教学功能 |
|--------|-----------|---------|
| 弹力与激光微小形变3D演示.html | 弹力 · 微小形变 | 激光放大法演示桌面微小形变，拖动木块观察形变与激光光点的实时变化 |
| 机械能守恒定律-3D交互仿真.html | 机械能守恒 | 单摆摆动过程中动能与重力势能的实时转化，可点击最高点/最低点放置摆球 |
| 牛顿管3D.html | 自由落体 | 管内羽毛与铁片在真空 vs 空气中下落对比，支持抽气/放气、倒立释放 |
| 探究功热和内能的改变-3D.html | 功、热与内能 | 压缩/膨胀气体做功、加热热源对气体的影响，双缸对比演示热力学第一定律 |
| 运动的描述-x-t与v-t图像3D动态模型.html | 运动的描述 | 匀速/匀加速/匀减速/简谐运动/分段运动的 x-t、v-t 动态图像与小车联动 |
| 追及相遇双小车3D.html | 追及与相遇 | A 车加速追 B 车匀速，实时显示距离最远、相遇时刻，支持参数调节 |
| 伽利略理想斜面实验-3D交互版.html | 伽利略理想实验 | 理想斜面与真实斜面对比演示 |
| 奶龙瓶微小形变3D演示.html | 微小形变 | 玻璃瓶微小形变的光放大演示 |
| 汽车刹车匀减速3D交互Demo.html | 匀减速直线运动 | 汽车刹车过程的匀减速运动演示 |

## 运行方式

### 方式一：直接打开（最简单）
双击任意 `.html` 文件，用 Chrome 或 Edge 浏览器打开即可。

### 方式二：本地 HTTP 服务器（推荐，确保 Three.js CDN 加载稳定）
```bash
# Python 3
python -m http.server 8080

# 然后访问
# http://localhost:8080/public/visual-classroom/physics/必修一/
```

### 方式三：集成到数智课堂
将整个 `public/visual-classroom/physics/` 目录放入 Huishi-class 仓库对应位置即可。

## 技术栈
- **Three.js** 0.128 — 3D 渲染引擎
- **OrbitControls** — 相机轨道控制（鼠标拖拽旋转、滚轮缩放、右键平移）
- **CanvasTexture** — 动态生成 3D 标签文字
- 纯静态 HTML/CSS/JavaScript，零构建步骤

## 交互说明
- **鼠标左键拖拽**：旋转 3D 视角
- **鼠标滚轮**：缩放
- **鼠标右键拖拽**：平移视角
- **点击 3D 场景中的标签按钮**：执行对应教学动作（下压活塞、开启加热、跳转到最远时刻等）
